Use case: ui-mockup
Asset type: overall visual design reference for a real personal task management application, Windows-first with responsive web and Android layouts.
Primary request: Create one polished product design board showing a large Windows desktop app interface on the left and a smaller matching mobile interface on the right. App name "日序" with small English wordmark "DAYWEAVE". Designed for a Chinese researcher managing parallel work with AI agents.
Style: exceptionally clean calm editorial productivity UI, warm off-white background, very pale sage sidebar, deep forest-green primary actions, charcoal type, fine light-gray borders, generous spacing, restrained rounded corners, no gradients or flashy neon. Flat front-on UI, crisp readable Chinese typography.
Desktop structure: narrow left sidebar with logo 日序, nav 今天 / 全部任务 / Agent 协作 / 已结束, mini month calendar, bottom 云同步 settings. Main panel header "把今天，理出头绪。" and date "10月20日，星期二", green 新建任务 button. Muted badges like 自己 / Codex / 等待反馈, tiny project and priority tags. On the right a slim focus summary with a circular daily-progress indicator, "专注当下", one important task and "给并行任务，留一点秩序。" Bottom subtle keyboard hints. All task groups and rows have chevrons.
Mobile: same visual language in single column, compact header, week strip, stacked task lists, bottom navigation 今天 / 全部 / 协作 / 设置, floating green plus.
Constraints: This is a realistic buildable UI design reference, not a marketing landing page; no stock photos, no decorative 3D objects, no window stacks obscuring content, avoid overfull dashboard statistics. Give task content the majority of space.
