# v0.4.0 验证记录

验证日期：2026-10-20。

## 行为

- 所有过去日期、未删除、没有待解决冲突的进行中任务，沿用原 ID 顺延到当前设备的今天。跨零点、焦点恢复、唤醒、重新打开与远程拉取都处理；连续多天未打开时直接补齐到今天。保留执行者、子步骤、完成进度、备注、排序及产出关联，不复制任务或文件。
- 待办、已结束、未来任务不移动；存在真实编辑冲突时先由用户选择版本。多台设备只对同一任务做等价日期顺延时自动合并，内容不同则继续保留双方。
- 主界面停在今天时随日期切换，明确选择的历史 / 未来日期保持不变。关闭所有客户端期间不运行客户端逻辑，下次打开补齐；无后台常驻进程或数据库定时任务。
- API 支持本人账号任务的读取、创建、局部修改、软删除。设置中管理只读 / 读写密钥、30 / 90 / 365 天期限及撤销。完整密钥只显示一次，数据库保存摘要，客户端不持久化密钥。
- API 使用共享任务验证，拒绝身份覆盖、未知字段、本机路径及附件写入；文件仍需在客户端主动选择云存储。所有写入需幂等 UUID，修改和删除需版本号。

## 自动化与云端

- 单元测试 18 项通过，TypeScript 和生产构建通过；无新增运行时依赖。
- 桌面与手机模拟交互 28 项通过，包括连续跨天、离线重启补齐、完成后停止移动、历史日期选择保持、密钥摘要生成 / 一次展示 / 重开不泄漏 / 撤销。
- 实际 Supabase 部署 `personal_task_api` 迁移与 `dayweave-api` Edge Function。`verify_jwt=false`，函数每次自行校验个人密钥；带用户参数的写入 RPC 只授权 service_role，不授予普通账号或匿名者。
- `tests/api-rls.sql` 在回滚事务中通过：本人创建、密钥摘要列不能读取、他人密钥不可读 / 不可撤销、普通用户不可执行服务端 RPC、不可改权限列、原子 60 次 / 分钟限流与撤销。
- 使用两个独立临时账号调用实际 HTTPS API：公开 OpenAPI、无密钥 401、新建 201、重复重试不重复创建、单项查询、原样回传网关弱 ETag 修改、过期版本 409、步骤保留、软删除、跨用户读写 404、身份注入 400。另实测只读写入 403、撤销 / 过期 401、超限 429。
- 云端临时测试账号、密钥和任务已清理；本机临时明文测试密钥文件已移除，不触及用户正常数据。
- Supabase advisor 未报新增数据库权限问题；原有密码泄漏保护提示和未使用索引信息不由本轮产生，未更改 Auth 配置。
