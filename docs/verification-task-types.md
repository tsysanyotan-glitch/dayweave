先使用内置 ImageGen 分别生成 [电脑设计](design/dayweave-task-types-desktop.png) 和 [手机设计](design/dayweave-task-types-mobile.png)，再编码。提示词保存于 [设计记录](design/task-types-prompts.md)。

## 功能与兼容

- 计划任务：绿色清单图标和文字标签；零碎问题：琥珀色扳手、文字标签、浅色底和左边色条。精简窗口保留不同形状的图标，识别不依赖颜色。
- 类型与三个状态、优先级、执行者、子步骤及产出独立；转换类型不会重新创建或删除任务。
- 支持全部 / 计划任务 / 零碎问题筛选，筛选选择在刷新后保留；从零碎问题筛选创建时预选该类型。
- 老任务、旧备份缺少类型时默认归为计划任务；类型字段随任务文档同步并包含在 JSON 备份中，无需修改数据库结构。
- 早期客户端会忽略未知字段，建议所有设备升级到 v0.2.1 后使用类型功能。
