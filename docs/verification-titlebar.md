# v0.2.2 窗口顶栏调整

验证日期：2026-10-20。

## 调整范围

- Windows 禁用系统窗口装饰，移除重复的黑色标题栏。最小化、最大化 / 还原、关闭按钮位于现有应用顶栏右侧。
- 顶栏空白区域可拖动，双击最大化或还原。交互按钮不触发窗口拖动。
- 顶栏在页面滚动时保持可见；精简窗口保留窗口按钮、置顶、设置和恢复完整视图。
- 从最大化进入精简窗口会先退出最大化；恢复完整视图时恢复原先的最大化状态。
- 网页和手机界面不显示 Windows 窗口按钮。任务数据、云端协议和本机文件保存方式沿用上一版。

## 网页回归

- 11 项单元检查通过。
- 14 项桌面 / 手机浏览器交互检查通过，覆盖任务、离线刷新、子步骤、拖拽、精简视图、本机附件、回收站和任务类型。
- TypeScript 和生产构建通过；未新增运行时依赖。

## Windows 程序实测

- Windows x64 release 与 NSIS 打包通过。启动实际 release 程序，版本读回为 `0.2.2`，原生 `isDecorated()` 返回 `false`。
- 在独立 WebView 测试数据目录中，通过实际原生窗口状态验证：顶栏双击最大化、自定义最大化 / 还原按钮、从最大化切到精简后恢复最大化、置顶 / 取消置顶、最小化，以及关闭后程序退出。
- 精简窗口宽 330 逻辑像素时，设置、置顶、视图切换与三个窗口按钮均在可视区域内，无横向溢出。长页面滚动时关闭按钮仍可见。
- 创建计划任务和零碎问题后刷新，任务保留。查看实际桌面与精简窗口截图，顶栏按钮与任务内容清楚可见。测试未出现页面错误。
- 原生拖动区域使用 Tauri 自带处理器，并启用拖动权限；本次自动检查验证双击最大化，未模拟系统鼠标拖动或多显示器跨屏移动。
- 测试使用独立数据空间，没有读写用户任务或本机产出文件。
