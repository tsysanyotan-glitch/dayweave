# v0.2.3 滚动条外观调整

验证日期：2026-10-20。

## 调整

主页面、设置弹窗、任务编辑弹窗和备注输入区隐藏可见滚动条。使用标准 `scrollbar-width: none` 和 WebKit 滚动条样式，保留浏览器原有滚动容器与滚动范围，没有设置 `overflow: hidden` 或拦截滚动事件。

- TypeScript 与生产构建通过，14 项桌面 / 手机浏览器交互回归通过。
- 桌面实际发送滚轮事件，验证长页面、设置弹窗能够向下滚动、查看底部并返回顶部。
- 手机布局实际发送触摸开始、移动、结束事件，验证主页面和设置弹窗可上下滑动，底部关于信息能够显示。

- 长备注输入区隐藏滚动条，任务编辑和保存正常。
- 检查未出现页面错误，使用隔离的浏览器数据空间。
