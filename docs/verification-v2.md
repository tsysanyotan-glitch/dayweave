| 单元测试 | 10 项通过；含旧任务兼容、元数据排除本机路径和字节、附件本机持久化、账号空间隔离与显式复制 |

| Rust 原生逻辑 | 1 项通过；登记表读写、路径不出现在附件元数据、文件夹 ZIP 内嵌套中文文件名与内容保持一致、非法账号空间拒绝 |
| 真实云端联调 | 两个一次性账号、三个隔离数据空间；登录、Realtime、离线冲突保留及账号隔离通过 |
| 真实文件链路 | 关联本机文件不会上传；确认前无云端对象；上传后另一设备只见名称和私有引用；手机尺寸下载内容逐字节一致；其他账号和匿名访问、跨账号写入被拒绝 |
| 撤回云端副本 | 保留本机副本后删除 Storage 对象，列表为空且带新缓存标识的下载被拒绝；其他设备已下载的副本仍保留 |

Storage 使用私有 `task-outputs` bucket，限制 25 MB，SELECT / INSERT / DELETE 均限定登录账号的路径前缀。新增迁移已应用到开发项目。文件上传使用零缓存有效期，下载添加唯一缓存标识，避免撤回后误用此前缓存来判断云端状态。

一次性账号的云端文件经 Storage API 清理，并确认对象数为零后删除测试账号和任务；本机测试凭据文件已移除。
