# v0.3.0 验证记录

验证日期：2026-10-20。

## 本轮变化

- 邮箱与 6 位验证码登录，移除密码和注册切换。新邮箱验证后自动创建账号，旧邮箱继续使用原账号。
- 使用真实 Supabase SDK 的发码与验证码验证方法；验证码保留前导零。错误或过期提示、60 秒重发倒计时、修改邮箱、设置窗口重新打开后继续输入。
- 取消桌面和手机的 Agent 协作栏目；导航统一为今天、全部任务、已结束。
- 执行者改成自定义标签，保存任务时创建；在同一任务空间中可以复用已用标签和筛选。标签与任务一起保存和同步，没有新增数据库表。
- 精简窗口最小 280 × 260，完整窗口最小 320 × 360（逻辑像素）。记住精简窗口尺寸，适配系统缩放。短窗口通过搜索按钮展开筛选，较宽窗口显示类型、项目、优先级和备注预览。
- 本轮使用内置 ImageGen，先生成 [电脑设计](design/dayweave-v3-desktop.png) 和 [手机设计](design/dayweave-v3-mobile.png)，再编码；[提示词记录](design/dayweave-v3-prompts.md)。沿用现有标志、鼠尾草绿和暖白配色。
